# Objave za @pametnija.firma

Instagram @pametnija.firma i Facebook stranica "Pametnija firma": automatizacija poslova, nadzor sistema i AI za male i srednje firme.

- `objave/GGGG-MM-DD_tema/`: video.mp4, cover.jpg, opis.txt (+ alt.txt, ai.txt, scenarij.py). GitHub Actions ih objavljuje svaki dan od 17:43.
- `pravila/`: VODIC.md (sve upute), mediji.md (fotke i glas), zajednica.md, plan_objava.csv.
- `alati/`: animacija.py (animirani Reel), objavi.py, komentari.py, napravi_story.py, muzika.py.
- `arhiva/video-nadzor/`: stari profil @video.nadzorkamere (obrisan 20.11.2026), samo za historiju.

Fotografije i glas u objavama su napravljeni AI alatom i to piše u opisu svake objave.
